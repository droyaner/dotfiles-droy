*Droys cheatsheet*

Useful commands:
  :.!date                 Insert command output at cursor line
  :%s/search/replace/g    Replace in whole file (with g = all matches)
  :%s/search/replace/gc   Replace in whole file with confirmation

Inner/outer text objects:
  ci"    Change inside quotes
  ca"    Change around quotes (incl. quotes)
  ci(    Change inside parentheses
  ca(    Change around parentheses
  di{    Delete inside braces
  da{    Delete around braces
  viw    Select inner word
  vaw    Select around word

Marks:
  ma         Set mark a at cursor (a-z)
  'a         Jump to start of line of mark a
  ''         Jump back to previous jump position
  :marks     List all marks
  :delmarks a    Delete mark a
  :delmarks!     Delete all local marks

Macros:
  q<register>    Start/stop recording a macro in a register
  @<register>    Execute the macro from the register
  @@            Repeat the last macro
  :reg          Show all registers
  Macros record a series of keystrokes and are handy for repetitive edits.

Tips:
  - Press <leader> and wait to discover mappings via which-key.
  - Run :help for built-in docs and :checkhealth for diagnostics.
